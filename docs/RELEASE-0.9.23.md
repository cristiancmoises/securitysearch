# SecuritySearch v0.9.23

Application 0.9.23 · asset marker 27 · retains v0.9.22-r1/r2 safeguards.

## English

Remove libre.securityops.co from active news routing. The compiled external default
is redlib.privacyredirect.com, with redlib.nadeko.net and redlib.privadency.com as
fixed sequential alternatives. Deployment requires actual nonempty parsed feed
AND keyword search results from one instance on the VPS candidate network, then
persists that tested origin in the replacement. Empty results/challenge pages do
not qualify. Failures retain production and write a sanitized selection report.
Listing an instance is not a guarantee of availability; no authoring-side live
search or all-provider speedup is claimed. Existing budgets, origin-bound
pagination, query-sharing disclosure and no personal-search cache remain.

Repair My picture's actual Settings POST CSP mismatch and missing editor. Add a
clear native opt-in button, an automatically opened editor before theme tiles,
a visible file chooser and preview, and readiness/errors instead of a silent dead
control. Files are recognized by bounded raster signatures rather than unreliable
OS MIME labels. JPEG/PNG/WebP/GIF are accepted (GIF becomes a still), up to 16 MiB
and 48 megapixels after decode; outputs stay within 1920px and 2 MiB data URLs.
HEIC/HEIF and SVG remain unsupported. File data never enters a form or network API.
Tab-session storage stays the default; device persistence is explicit. A blocked
store falls back to page-only display with an honest message. Failed replacement
preserves the previous picture. Ordinary searches still work without JavaScript;
the local picture feature requires the optional same-origin script.

The new patch retains all 43 previous test commands and adds four mandatory suites.
The full extension-enabled Docker gate remains required. Browser fixtures used
actual file selection/decoding/canvas/display, but managed browser navigation was
blocked: embedded-resource fixture rendering is not a production navigation pass.
See the audit report for exact passed/blocked results.

## Português do Brasil

libre.securityops.co deixa de ser usado nas notícias. O padrão externo compilado é
redlib.privacyredirect.com, com redlib.nadeko.net e redlib.privadency.com como
alternativas sequenciais fixas. O deploy exige resultados reais reconhecidos de
feed E busca por palavra-chave na mesma instância pela rede do candidato. A origem
aprovada é persistida no novo contêiner. Falha não para a produção; o relatório
sanitizado fica no backup. A lista não comprova disponibilidade e não há promessa
de ganho medido em todos os provedores. Paginação e avisos mantêm a origem correta.

Corrige o CSP calculado antes da preferência no POST de Configurações e o editor
ausente. Um botão nativo abre o seletor antes dos temas; arquivo e prévia ficam
visíveis. Os bytes são validados mesmo quando o MIME está vazio. JPEG/PNG/WebP/GIF
são aceitos (GIF estático), com entrada até 16 MiB e 48 megapixels após decodificar;
a saída fica até 1920px e 2 MiB. HEIC/HEIF e SVG não são aceitos. Não há upload.
A sessão da aba é padrão, persistência no dispositivo é explícita, erros não
apagam a imagem anterior e bloqueio de armazenamento permite exibição só na página.
Busca comum continua sem JavaScript; a imagem local requer o script opcional.

Permanecem os 43 comandos de teste anteriores; quatro novas suítes são obrigatórias.
A auditoria Docker completa continua necessária. As fixtures de navegador usaram
seleção e decodificação reais, mas navegação foi bloqueada pela política do ambiente;
a renderização com recursos embutidos não é validação da navegação em produção.
