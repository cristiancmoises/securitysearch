# SecuritySearch v0.9.21

Application **0.9.21** · asset **25** · builds on the published v0.9.20 tree and keeps the r1 audit correction.

## English

Bounded sequential Redlib fallback, instance-pinned news pagination, a sixty-second
public query-free news-feed cache, and narrowly scoped network-failure cooldowns.
Posters stay visible while animated image layers load; Play/Pause, two-loading /
four-active limits and accessibility preferences are preserved. No measured
all-provider speedup or uptime guarantee is claimed.

Black remains default. Eighteen working preview choices include animated Tron,
a cyan SecOps alternative using bundled Matrix art, and browser-only My picture.
Dark/Wine/The Birthday Massacre are removed; native selects use black and theme
accent colors. Custom picture files are not uploaded; session storage is default
and persistent storage is an explicit choice. The site says Works without
JavaScript, not a false universal No JavaScript claim.

A Tor/onion link and dated Tranco cache appear in the footer. The optional daily
refresh is separate from page rendering and sends only the public domain; no
unverified rank is included. Canonical/social/sitemap metadata is updated and
private searches/settings remain noindex. Included screenshots are isolated
local PHP/Chromium renderings, not live-VPS captures.

The native fish kit applies, deploys and publishes separately. It retains full
offline/candidate/Binternet gates and rollback. Publication preflights selected
hosts, pushes matching annotated tag/main without force, uploads source tar.gz
and SHA-256 to a draft using the appropriate GitHub/Forgejo upload format,
verifies bytes, and only then publishes. `--host git.securityops.co` resumes only
that host including assets. Conflicting tags, notes and files are never replaced.

## Português do Brasil

Fallback Redlib sequencial limitado, paginação presa à instância que respondeu,
cache de sessenta segundos somente do feed público sem consulta e pausas curtas
para falhas inequívocas de rede. Posters permanecem enquanto animações carregam,
com Play/Pause, limites e preferências de acessibilidade. Não se promete ganho
medido em todos os provedores nem disponibilidade total.

Preto permanece padrão. Há dezoito prévias funcionais, Tron animado, alternativa
SecOps em ciano/Matrix e My picture somente no navegador. Dark/Wine/The Birthday
Massacre saem; seletores usam preto e a cor do tema. Imagens pessoais não são
enviadas: armazenamento da aba é padrão, persistência é opcional. Works without
JavaScript reconhece os recursos opcionais que utilizam scripts locais.

Rodapé com onion/Tor e metadados Tranco datados, atualizados fora das requisições.
Nenhuma posição não verificada é incluída. Metadados canônicos/sociais/sitemap
foram corrigidos; buscas/configurações privadas permanecem noindex. As capturas
são renderizações locais isoladas, não a VPS atualizada.

O kit mantém auditoria completa, prontidão, teste Binternet e rollback antes da
troca. Publicação gera tag anotada, tar.gz e SHA-256 do commit real, valida uploads
e retoma somente um host com `--host`. Não força nem substitui tags/anexos conflitantes.
