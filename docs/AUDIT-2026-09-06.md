# v0.9.11 audit — 6 September 2026

Scope: changed source, Google transport, pagination failures, image views,
first-visit theme, Docker resource/configuration preservation and status routing.
This is a scoped engineering audit, not a certification or claim of zero bugs.

- PHP syntax: all 90 PHP files present during the initial pass passed lint.
- Offline regressions: layouts, invalid inputs, saved themes, malformed JSONP,
  provider challenges, monotonic deadline, cooldown and authenticated pagination
  token rejection/replay passed. Invalid attempts leave the valid token usable.
- Chromium: all four layouts at 360, 768 and 1440 px, with JavaScript disabled,
  rendered 20 actual Google image results and no horizontal page overflow. Lain
  v14 was selected and the background was black. Mobile compact and desktop
  gallery screenshots were visually reviewed.
- Existing image proxy rejected loopback and file:// probes with HTTP 404.
- HTML provider errors returned HTTP 503, no-store and Retry-After: 30 rather
  than an HTML error hidden behind HTTP 200.
- Real Google web results passed locally and from the IONOS candidate. Google
  also returned an anti-abuse failure on an image request through the configured
  pool; Brave issued a challenge. Neither provider's availability is guaranteed.
- Status routing: private bridge and public `/status/en.html` returned HTTP 200.
  Two later public snapshots measured 2.85 s and 2.59 s from the operator's local
  network. These are observations, not a before/after benchmark or uptime SLA.
- NPM had a global JSON Content-Type and wildcard CORS; those were removed from
  this search host while preserving application MIME types and security policy.
- Candidate validation caught a missing secondary Docker network required for
  private proxy DNS. Deployment now preserves every existing network; Tor proxy
  containers and private pools were retained rather than silently bypassed.

Known limits: datacenter/Tor egress can be challenged, original images can be
large/unavailable, and status reflects scheduled snapshots rather than continuous
proof. Search-result pages remain noindex. No artificial traffic or growth claim.

Português: os testes cobrem as alterações e regressões descritas, não garantem
ausência de bugs. Os quatro layouts passaram sem JS em três larguras. O 502 do
status foi corrigido na rota; bloqueios externos de Google/Brave continuam sendo
informados honestamente. Nenhum pool privado ou túnel existente foi substituído.
