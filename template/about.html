Set as default search engine

On Firefox and other Gecko based browsers

 To set this as your default search engine on Firefox, right click the URL bar and select
Add "4get"
. Then, visit about:preferences#search and select
4get
in the dropdown menu.

On Chromium and Blink based browsers

 Click the 3 superpositioned dots at the top right of the screen and click on
Settings
, then search for
default search engine
, or visit chrome://settings/searchEngines.

Once you're there, click the pencil on the last entry under "Search engines" (it's probably DuckDuckGo). Once you do that, a popup will appear. Populate it with the following information:
Field Value
Search engine {%server_name%}
Shortcut {%server_name%}
URL with %s in place of query https://securityops.co/web?s=%s
Once that's done, click
Save
. Then, on the right handside of the newly created entry, open the dropdown menu and select
Make default
.

Frequently asked questions

What is this?

 Security Search is a privacy-focused metasearch interface. It requests results from the provider you select, removes known tracking parameters, and returns a lightweight page without advertising or third-party analytics.

My goal

 Provide a lightweight, ad-free and open-source way to search the web with minimal optional JavaScript. The landing page deliberately keeps the logo and search field as its visual focus.

Do you keep logs?

 The service temporarily stores the state required to request the next page of results. This can include the query, filters and provider tokens. The state is encrypted with
libsodium
; the browser receives the corresponding continuation token, known internally as
npt
. Encrypted continuation data expires after 15 minutes or is removed when used, whichever comes first.

Security Search does not create application-level search-history profiles. Continuation state is held temporarily in memory and encrypted. Infrastructure access logs, if enabled by an operator, are a separate deployment concern.

Do you share information with third parties?

 Your query and selected filters are sent to the upstream search provider so it can return results. The provider sees the Security Search server connection rather than a direct browser request, but a query can still identify you if you put personal information in it. Security Search does not add ads, third-party analytics or behavioral profiling.

In short: assume the selected provider can read the query, and avoid including personal or confidential information.

Where is this website hosted?

 The public service is operated for the SecurityOps community. See Chat and securityops.com.br for the current project links.

How can I verify the service?

 The source code is available in the Security Search repository, where you can review it or host your own instance. Self-hosting gives you control of the server, but the selected upstream provider still receives queries from that server's network address.
